Steps for analyzing a dataset.

Step 1: Load the dataset
1.1 Import any needed libraries.
1.2 Read the file from wherever is is (database, Excel, sharepoint list, etc).

Step 2: Clean the database
2.1 View the top few rows of the data set to see what the format and columns look like.
2.2 Scan and remove duplicates.
2.3 Organize the data so that the columns are seperated into like groups. Make sure the data formats are
setup correct. For example, columns with numbers are integers, or text is listed as a string.
2.4 Look for unreasonable values like NaN's or impossible percentages. 

Step 3: Calculate Summary Statistics
3.1 Find mean, median, & mode for key numerical categories
3.2 Start initial searches for variability like ranges, standard deviation, spreads. A boxplot could come in 
handy here.
3.3 Create correlation matricies if applicable to the see the strengths of some relation ships versus others.

Step 4: Create a Visualization
4.1 Create boxplots and histograms for general numerical data or categorial data. Use maps with hotspots to show
data across different states. Use trend over time charts to see how data changes over time.

Step 5: Interpret Results
5.1 Apply labels, titles, create keys, etc. Add colors that go along with what's being done.
5.2 Combine like charts together in dasboards if using something like PowerBI or Tableau.
